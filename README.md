# kshmotives | Portfolio — как запустить сайт

## 1. Подготовь 2 видео
Экспорт из Premiere / Media Encoder:
- Формат **H.264**, контейнер **.mp4**
- Битрейт: **VBR 1 pass, целевой 3–4 Мбит/с** (вертикалка 1080×1920, горизонталка 1920×1080)
- Аудио: **AAC 192 кбит/с**
- Галочка **Fast Start / оптимизация для веба** (если есть) — видео начнёт играть сразу
- Каждый файл **меньше 25 МБ**. Ролик 60 сек на 3 Мбит/с ≈ 23 МБ. Длиннее — снижай битрейт до 2–2,5 Мбит/с.

Назови файлы строго:
- `videos/horizontal.mp4`
- `videos/vertical.mp4`

Обложки (необязательно): `videos/horizontal.jpg`, `videos/vertical.jpg` — кадр из ролика, JPG до 300 КБ. Без них показывается первый кадр видео. Длительность ролика на карточке подставляется сама.

## 2. Залей на GitHub
1. Зарегистрируйся на github.com.
2. Справа вверху **+ → New repository** → имя `kshmotives` → Public → **Create repository**.
3. На странице репозитория: **uploading an existing file** → перетащи ВСЁ содержимое папки сайта (index.html, styles.css, app.js, i18n.js, иконки, og.png, папки images и videos).
   Важно: перетаскивай содержимое папки, а не саму папку — `index.html` должен лежать в корне.
4. Внизу **Commit changes**.

## 3. Опубликуй на Vercel
1. vercel.com → **Sign Up → Continue with GitHub** (тариф Hobby, бесплатно).
2. **Add New… → Project** → напротив `kshmotives` нажми **Import**.
3. Framework Preset: **Other**. Остальное не трогай → **Deploy**.
4. Через ~30 сек сайт будет по адресу вида `kshmotives.vercel.app`.
   Если адрес другой: Project → **Settings → Domains** → добавь `kshmotives.vercel.app` (если свободен).
   Если адрес в итоге другой — замени `https://kshmotives.vercel.app` на свой в `index.html` (строки og:image и og:url), чтобы превью ссылки в Telegram было с картинкой.

## 4. Как вносить правки
Любой файл меняешь прямо на GitHub (иконка карандаша → Commit) или загружаешь новый с тем же именем — Vercel сам пересобирает сайт за минуту.
- Тексты RU/EN — в `i18n.js`
- Заменить видео — загрузи новый `horizontal.mp4` / `vertical.mp4` поверх старого

## 5. Проверка
- Открой сайт с телефона на **мобильном интернете без VPN** — так его увидит клиент.
- Ссылка на английскую версию: `https://kshmotives.vercel.app/?lang=en`
- Кинь ссылку себе в Избранное в Telegram — проверь превью.

## YouTube не нужен
Видео лежат прямо на сайте (Vercel). YouTube в РФ замедлен — клиент без VPN не посмотрит. Свои файлы грузятся у всех.

## Когда появится первый клиент
В `index.html` найди блок `id="clients"` — замени пустую карточку на отзыв/логотип/скрин переписки (с разрешения клиента).
